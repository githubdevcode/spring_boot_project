1. Useful commands related spring sts.
	@ List
		1. Search and Navigation
			- List
				1.1 Ctrl + Shift + T
					- Name
						! Open Type
					- Descripcion
						! Encuentra cualquier codigo fuente de clase java o interfaz java a traves que se encuentre en los archivos del proyecto
							o en cualquier dependencia externa como un archivo .jar
				1.2 Ctrl + Shift + R
					- Name
						! Open Resource
					- Descripcion
						! Encuentra cualquier archivo que no sea un archivo relativo a java como:
							1. application.properties
							2.1 fuentes:
									2.1.1 html
									2.1.2 css
									2.1.3 xml
									2.1.4 etc... 
							3. etc...
				1.3 Ctrl + Alt + Shift + L
					- Name
						! Quick Search
					- Descripcion
						! Permite buscar cualquier texto en:
							@ Lista
								1. Todos los archivos de texto que se encuentran en cada uno de los proyectos abiertos.
								2. Un archivo de texto especifico que se encuentre en alguno de los proyectos abiertos.
					- Importante
						1. Como se va escribiendo el texto asi automaticamente se realiza la busqueda de ese texto.
				1.4 Ctrl + O
					- Name
						! Quick Outline
					- Descripcion
						! Despliega todas las:
							@ Lista
								1. Variables
								2. Metodos
							para una navegacion rapida en un elemento java como puede ser:
								@ Lista
									1. Clase
									2. Interface
									3. etc..
							
					- Importante
						1. Tambien permite buscar por medio de texto cada elemento java descrito.
				1.5 F3
					- Name
						! Open Declaration
					- Descripcion
						! Permite ir a la definicion de un elemento en java:
							@ Lista
								1. Variable
								2. Metodo
								3. Clase
								4. etc...
				1.6 F4
					- Name
						! Types Hierarchy
					- Descripcion
						! Muestra de una clase:
							@ Lista
								1. La jerarquia de clases
								2. Metodos
								3. Variables
								4. Subclases
								5. etc...
