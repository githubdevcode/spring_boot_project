1. Useful commands related spring sts.
	@ List
		1. Search and Navigation
			- List
				1.1 Ctrl + Shift + T
					- Name
						! Open Type
					- Descripcion
						! Encuentra cualquier codigo fuente de clase java o interfaz java a traves que se encuentre en los archivos del proyecto
							o en cualquier dependencia externa como un archivo .jar
				1.2 Ctrl + Shift + R
					- Name
						! Open Resource
					- Descripcion
						! Encuentra cualquier archivo que no sea un archivo relativo a java como:
							1. application.properties
							2.1 fuentes:
									2.1.1 html
									2.1.2 css
									2.1.3 xml
									2.1.4 etc... 
							3. etc...
				1.3 Ctrl + Alt + Shift + L
					- Name
						! Quick Search
					- Descripcion
						! Permite buscar cualquier texto en:
							@ Lista
								1. Todos los archivos de texto que se encuentran en cada uno de los proyectos abiertos.
								2. Un archivo de texto especifico que se encuentre en alguno de los proyectos abiertos.
					- Importante
						1. Como se va escribiendo el texto asi automaticamente se realiza la busqueda de ese texto.
				1.4 Ctrl + O
					- Name
						! Quick Outline
					- Descripcion
						! Despliega todas las:
							@ Lista
								1. Variables
								2. Metodos
							para una navegacion rapida en un elemento java como puede ser:
								@ Lista
									1. Clase
									2. Interface
									3. etc..
							
					- Importante
						1. Tambien permite buscar por medio de texto cada elemento java descrito.
				1.5 F3
					- Name
						! Open Declaration
					- Descripcion
						! Permite ir a la definicion de un elemento en java:
							@ Lista
								1. Variable
								2. Metodo
								3. Clase
								4. etc...
				1.6 F4
					- Name
						! Types Hierarchy
					- Descripcion
						! Muestra de una clase:
							@ Lista
								1. La jerarquia de clases
								2. Metodos
								3. Variables
								4. Subclases
								5. etc...
				1.7 Ctrl + E
					- Name
						! Quick Switch Editor
					- Descripcion
						! Abre una lista con recursos abiertos aun y permite ir a ellos como tambien buscarlos e ir.
				1.8 Ctrl + F6
					- Name
						! Next Editor Tab
					- Descripcion
						! Es como el comando anterior del punto 1.8 salvo que no hay barra de busqueda y se pasa al
							siguiente recurso pulsando F6.
				1.9 Ctrl + M
					- Name
						! Maximize Window
					- Descripcion
						! Permite abrir y cerrar el panel lateral donde se muestra el proyecto.
				2.0 Ctrl + W
					- Name
						! Close Tab
					- Descripcion
						! Permite cerrar un tab abierto.
				2.1 Ctrl + T
					- Name
						! Quick Type Hierarchy
					- Descripcion
						! Permite desplegar un cuadro con todos los:
							@ Lista
								1. Interfaces
								2. Super clases
							que extiende o implementa un elemento java.
				2.2 Ctrl + Alt + H
					- Name
						! Call Hierarchy
					- Descripcion
						! Al seleccionar un metodo cualquiera y despues ejecutar este atajo muestra todos los
							metodos relativos al metodo seleccionado que:
								@ Lista
									1. Llaman al metodo seleccionado
									2. Son llamados por el metodo seleccionado
				2.3 Alt + Left Arrow
					- Name
						! Back / Previous Location
					- Descripcion
						! Lleva el puntero del raton al ultimo archivo y linea que se modifico o en el que 
							se estuvo.
				2.4 Alt + Right Arrow
					- Name
						! Forward Location
					- Descripcion
						! Lleva el puntero del raton al proximo archivo y linea que se modifico o en el que 
							se estuvo.
				2.5 Alt + Shift + Q
					- Name
						! Show All Views
					- Descripcion
						! Permite desplegar un cuadro con distintas opciones relativas a distintos tipos de vistas.
				2.6 Ctrl + F7
					- Name
						! Next View Window
					- Descripcion
						! Se despliega un menu que permite ir a los distintos tipos de vistas mas primordiales.

							@ Lista

								2. Endpoints rest
								3. Todos los componentes de spring
								4. Funciones

									5. etc...

								2. Elimina imports que no se necesitan.

						! indent

						- Name
							! Move Lines 
						- Descripcion

										- UP Button
									2. Abajo
										- DOWN Button
				3.15 Ctrl + Alt + Up / Down Arrow
					- Name
						! Duplicate Lines
					- Descripcion
						! Permite duplicar una linea hacia:
							@ Lista
								1. Arriba
								2. Abajo
				3.16 Alt + Shift + A
					- Name
						! Toggle Block Selection
					- Descripcion
						! Permite seleccionar un bloque de codigo por medio de un cuadro ensanchable de manera que
							se puede hacer cosas con el texto como:
								@ Lista
									1. Añadir mas texto a las lineas de codigo ya existentes
									2. Escribir texto en varias lineas al mismo tiempo
									3. Borrar el texto que haya en varias lineas
					- Importante
						1. Para volver a cambiar el puntero del mouse a su estado original se debe ejecutar de nuevo
							este atajo de teclado.
				3.17 Ctrl + Delete
					- Name
						! Delete Next Word
					- Descripcion
						! Permite borrar la siguiente palabra desde donde se encuentra ubicado el cursor.
				3.18 Ctrl + Backspace
					- Name
						! Delete Previous Word
					- Descripcion
						! Permite borrar la anterior palabra desde donde se encuentra ubicado el cursor.
				3.19 Ctrl + Shift + X
					- Name
						! To Uppercase
					- Descripcion
						! Permite convertir el texto seleccionado en un texto en mayuscula.
				3.20 Ctrl + Shift + Y
					- Name
						! To Lowercase
					- Descripcion
						! Permite convertir el texto seleccionado en un texto en minuscula.				
				3.21 Ctrl + D
					- Name
						! Delete Line
					- Descripcion
						! Permite borrar una linea de codigo entera sin subrayarla.

		5. Refactorizar codigo

				5.1 Alt + Shift + R
					- Name
						! Rename
					- Descripcion
						! Permite cambiarle el nombre a un:
							@ Lista
								1. Metodo
								2. Clase
								3. Vraiable
								4. etc... 
				5.2 Alt + Shift + M
					- Name
						! Extract Method
					- Descripcion
						! Permite seleccionar un codigo y refactorizarlo de manera que quede en un nuevo metodo independiente

							referenciado por una variable local.

										2. Setters
										3. Hash Code
										4. Equals
										5. toString
								2. Generar constructores
								3. Renombrar metodos
									@ Lista
										1. Nombre
										2. Parametros
										3. Retorno
								4. etc...
